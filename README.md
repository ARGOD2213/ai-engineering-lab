# AI Engineering Lab

A hands-on lab for becoming an **AI Application / AI Backend Engineer** on top of a
Java + Spring Boot foundation.

This lab is about *using* existing AI models from well-engineered backends — not about
training models or ML research.

## Roadmap

| # | Milestone | Status |
|---|-----------|--------|
| 1 | Embeddings → pgvector → semantic search (no LLM) | in progress |
| 2 | Same experiment on Chroma, Qdrant, Redis | planned |
| 3 | RAG (retrieval + LLM answer generation) | planned |
| 4 | Tool calling and agents | planned |
| 5 | MCP | planned |

Each milestone builds on the previous one. Nothing is implemented ahead of time.
