# Weekly Notes

Your own learning log. One file per week keeps progress visible and gives you material
for interviews ("tell me about something you built and what you learned").

Suggested file name: `YYYY-Www.md` (for example `2026-W41.md`).

```markdown
# 2026-W41

## What I built
## What I learned (in my own words)
## What confused me / open questions
## Questions to ask ChatGPT
## Next week
```
